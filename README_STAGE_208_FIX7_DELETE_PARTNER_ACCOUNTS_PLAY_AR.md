# Stage 208 Fix7 — حذف حساب المتجر والسائق

تمت إضافة **حذف الحساب** داخل الإعدادات لكل من المتجر والسائق بدون تغيير الطلبات أو الطباعة أو الخرائط أو الإشعارات.

## المتجر
- الإعدادات > الأمان/الحساب > حذف الحساب.
- تأكيد واضح قبل الحذف النهائي.
- الخادم يتحقق أن الحساب Business فعلًا.
- يتم تعطيل المتجر وفصل مالكه وإزالة بيانات الاتصال/الصور الشخصية المرتبطة بالحساب.
- يتم حذف حساب Auth نفسه.
- تبقى سجلات الطلبات التاريخية محفوظة بدل حذفها بالـ cascade.

## السائق
- مركز حساب السائق > الإعدادات > حذف الحساب.
- الخادم يتحقق أن الحساب Driver فعلًا.
- يتم حذف Auth وملفات السائق التابعة له حسب علاقات ON DELETE الحالية.
- orders.driver_id يتحول إلى NULL في السجل التاريخي بدل حذف الطلبات.

## مطلوب مرة واحدة في Supabase قبل اختبار حذف متجر
1. نفّذ ملف:
   `supabase/stage_208_fix7_partner_account_deletion.sql`
2. انشر Edge Function:
   `npx supabase functions deploy delete-partner-account`

> لا تختبر الحذف على متجر/سائق حقيقي. أنشئ حساب اختبار مؤقت لكل دور واحذفه.
