# Stage 419 — تبسيط محرر العبوات/الأوزان

مبني فوق 418.

التغييرات فقط داخل واجهة إضافة/تعديل المنتج في تطبيق الشركاء:
- إبقاء اسم الخيار.
- إبقاء الوحدة.
- إبقاء السعر الأصلي.
- إبقاء سعر العرض الاختياري.
- إبقاء متوفر للعميل.
- إخفاء القيمة/العدد من الواجهة فقط.
- إخفاء اختيار افتراضية من الواجهة فقط؛ المنطق الداخلي والحفظ بقي كما هو.
- لا SQL ولا تعديل Supabase ولا RPC ولا الطلبات ولا الطباعة ولا الإشعارات.

ملاحظة: لم يتوفر Flutter SDK في بيئة تجهيز الملف هنا، لذلك يجب تشغيل flutter analyze والبناء على جهاز Windows قبل اعتماد النسخة.
