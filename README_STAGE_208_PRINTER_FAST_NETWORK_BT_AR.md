# Stage 208 – الطباعة السريعة + إصلاح الرموز + Bluetooth

التعديلات في هذه المرحلة محصورة في نظام الطباعة، بدون تغيير منطق الطلبات أو الشفتات أو بقية أجزاء التطبيق.

## ما تم تعديله
- إبقاء قبول الطلب مستقلًا عن نجاح/فشل الطباعة.
- تحسين محاولة الطباعة بنقرة واحدة عبر طابعة النظام المحفوظة، مع استرجاع الطابعة الافتراضية الحالية إذا تغيّر عنوانها داخل Android Print Service.
- الإبقاء على Wi‑Fi/LAN المباشر للطابعات الحرارية ESC/POS عبر IP/Port (غالبًا 9100) بدون نافذة طباعة.
- توضيح أن الطابعات العامة ذات التعريف الخاص مثل بعض Canon/Epson تستخدم Android Print Service وقد يفرض النظام نافذة تأكيد؛ لا يتم التحايل على حماية Android.
- إصلاح مربعات الأحرف في الإيصال عبر خط عربي + خط لاتيني احتياطي، وتنظيف placeholder glyphs.
- إزالة x/× من سطر الصنف؛ يظهر العدد ثم اسم الصنف بشكل بسيط، ويدعم أسماء المنتجات الإنجليزية والمختلطة.
- تحسين Bluetooth على Android 12+ بإضافة BLUETOOTH_SCAN إلى BLUETOOTH_CONNECT.
- فحص أن Bluetooth مفعّل قبل الاتصال.
- تحسين توافق Bluetooth Classic ESC/POS بثلاث محاولات اتصال: RFCOMM SPP آمن، غير آمن، ثم channel 1 كحل توافق أخير.
- إرسال بيانات Bluetooth/Wi‑Fi على دفعات صغيرة لتقليل امتلاء buffer الطابعة.
- تقليل دفعات USB وإعادة المحاولة مرة واحدة عند فشل نقل مؤقت.

## ملاحظة مهمة
الطباعة الصامتة المباشرة عبر Wi‑Fi متاحة عندما تكون الطابعة نفسها تدعم بروتوكولًا مباشرًا مثل ESC/POS TCP/9100. الطابعات العامة مثل Canon SELPHY التي تعتمد Android Print Service قد تتطلب نافذة النظام للتأكيد، وهذا قيد من Android/تعريف الطابعة وليس من زر هلا طلب.
