Stage 210 - توسيع دعم الطابعات Android

- إضافة خيار Bluetooth تلقائي (Classic + BLE).
- يعرض الطابعات المقترنة عبر Bluetooth Classic/SPP وأجهزة BLE القريبة في قائمة واحدة.
- يميز نوع الاتصال داخليًا ثم يستخدم المسار الصحيح عند اختبار الاتصال والطباعة.
- إبقاء المسارات القديمة Classic وBLE وUSB وWi-Fi/LAN بدون حذفها.
- الهدف هو تحسين التوافق مع Xprinter ومعظم الطابعات الحرارية ESC/POS وعدم إخفاء الطابعة لمجرد أنها Classic بينما الشاشة تبحث BLE فقط.
- لم يتم تعديل إشعارات Android أو Firebase أو منطق الطلبات.
- ملاحظة iOS محفوظة للنسخة الخاصة بـ iOS: دعم BLE المباشر + الشبكة، مع مراعاة قيود iOS على Bluetooth Classic/SPP غير MFi.
