# Stage 202 — طباعة طلبات المتجر

تمت إضافة نظام طباعة مستقل عن الشفتات والأقسام ومنطق الطلبات.

## مكان زر الطباعة
- لا يظهر للطلب الجديد قبل القبول.
- يظهر بعد قبول الطلب عندما يصبح `preparing` / قيد التنفيذ.
- بعد نجاح الطباعة يتحول النص إلى "إعادة طباعة".
- تظهر حالة آخر طباعة داخل بطاقة الطلب: تمت الطباعة / فشلت، مع الوقت.

## إعدادات المتجر > الطابعة
- اختيار طابعة من الطابعات التي يعرضها نظام التشغيل.
- دعم الطابعات المتاحة عبر Bluetooth / USB / Wi‑Fi / LAN بحسب تعريف الطابعة وخدمة الطباعة المثبتة على الجهاز.
- مقاسات: 58 / 76 / 80 / 112 mm + عرض مخصص 40–150 mm.
- حجم الخط: صغير / متوسط / كبير.
- عدد النسخ: 1 / 2 / 3 لكل نوع.
- نسخة مطبخ ونسخة كاشير بشكل مستقل.
- إخفاء الأسعار من نسخة المطبخ.
- تحديد محتوى الورقة: رقم الطلب، الزبون، الأصناف، الإضافات، الملاحظات، الأسعار، العنوان، اسم المتجر، الشعار.
- لغة الطباعة: حسب لغة المتجر / العربية / English. عند اختيار لغة المتجر يدعم العربية والإنكليزية والكردية وفق لغة التطبيق.
- طباعة اختبار.
- طباعة تلقائية بعد قبول الطلب (تتطلب اختيار طابعة ثابتة).
- قص الورق والجرس كخيارات توافقية؛ التنفيذ الفعلي يعتمد على تعريف/خدمة الطابعة.

## ملاحظات تقنية
- الإعدادات محفوظة محليًا على جهاز المتجر لأن اختيار الطابعة خاص بالجهاز نفسه.
- لا توجد أي SQL جديدة لهذه المرحلة.
- لم يتم تعديل نظام الشفتات أو جداولها أو ترتيب الأقسام والمنتجات.
- تمت إضافة حزمتَي `printing` و `pdf`، لذلك شغّل `flutter pub get` قبل البناء.
