# Stage 207 — طباعة آمنة لجميع أنواع الطابعات

هذا التعديل مبني فوق Stage 206 بدون تغيير الشفتات أو الطلبات أو السائق أو الخرائط أو بقية أجزاء النظام.

## التعديلات
- فصل قبول الطلب عن نجاح الطباعة: فشل الطابعة لا يمنع قبول الطلب أو تغيير حالته.
- الطباعة التلقائية بعد القبول أصبحت عملية مستقلة غير حاجزة.
- خدمة الطباعة في الجهاز تدعم الطابعات العامة (حبر/ليزر/حرارية عبر تعريف النظام).
- عند فشل الطباعة المباشرة على الطابعة الافتراضية، زر الطباعة اليدوي/طباعة الاختبار يفتح نافذة طباعة النظام كخيار آمن.
- ESC/POS المباشر بقي كما هو للطابعات الحرارية المتوافقة عبر Bluetooth / USB / LAN.
- Epson L6270 وأي طابعة غير ESC/POS يجب استخدامها عبر «خدمة الطباعة في الجهاز (متوافقة عامة)».
- رسالة واضحة عند فشل الطباعة بعد قبول الطلب: الطلب يبقى مقبولًا ويمكن إعادة الطباعة يدويًا.

## الاختبار المقترح
1. اختر «خدمة الطباعة في الجهاز».
2. جرّب «طباعة اختبار» واختر Epson L6270 من نافذة Android إن لم تنجح الطباعة الصامتة.
3. اقبل طلبًا جديدًا وتأكد أن القبول ينجح حتى لو كانت الطابعة مطفأة.
4. اضغط «طباعة» من الطلب المقبول لإعادة المحاولة.
5. للطابعة الحرارية ESC/POS اختر «اتصال حراري مباشر ESC/POS» واختبر USB/Bluetooth/LAN كما كان سابقًا.
