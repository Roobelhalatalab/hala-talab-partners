# Stage 201 — جدول أسبوعي مستقل لكل شفت

- الشفت الواحد: يبقى جدول الدوام الأسبوعي القديم كما هو.
- الشفتان: يظهر جدول مستقل للصباحي وجدول مستقل للمسائي.
- كل يوم يمكن تشغيل/تعطيل كل شفت بشكل مستقل.
- أوقات كل شفت لكل يوم مستقلة وتظهر بصيغة صباحًا/مساءً.
- يمنع الحفظ إذا تداخل الشفت الصباحي والمسائي في نفس اليوم.
- الشفت اللي يتجاوز منتصف الليل مدعوم.
- `store_shifts.weekly_hours` هو مصدر جدول الشفت الأسبوعي، مع fallback للأوقات القديمة.

شغّل مرة واحدة:
`supabase/stage_201_shift_weekly_schedules.sql`
