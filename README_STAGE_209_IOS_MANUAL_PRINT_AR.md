# Stage 209 — iOS Manual Print Ready

تمت إضافة مسار طباعة آمن خاص بـ iPhone/iPad بدون تغيير مسارات الطباعة الحالية على Android.

## iPhone / iPad
- زر **طباعة** داخل الطلب يفتح نافذة الطباعة الأصلية في iOS.
- المستخدم يختار/يؤكد الطابعة ثم يطبع الطلب.
- يعتمد على خدمة الطباعة في iOS / AirPrint أو الطابعات التي يعرضها النظام.
- لا يحاول استخدام Bluetooth Classic / USB / ESC-POS الخاصة بـ Android على iOS.
- الطباعة التلقائية الصامتة بعد قبول الطلب لا تفتح نافذة الطباعة على iOS؛ المستخدم يستخدم زر الطباعة يدويًا.

## Android
- لم يتم تغيير كود Java/Kotlin أو إعدادات Android للطباعة.
- Bluetooth Classic / BLE / USB / Wi-Fi-LAN ESC/POS تبقى كما هي.
- خدمة طباعة النظام والطباعة المباشرة تبقى كما هي.

## ملاحظة الاختبار
التحقق النهائي من نافذة الطباعة وAirPrint يجب أن يتم على macOS/Xcode وجهاز iPhone/iPad حقيقي عند مرحلة الـMac.
