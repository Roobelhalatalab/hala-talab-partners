# هلا طلب – الشركاء – Stage 204

## الطباعة الحرارية المباشرة ESC/POS

تمت إضافة طبقة طباعة مباشرة داخل تطبيق المتجر، فوق نظام الطباعة الموجود سابقًا، بدون تغيير نظام الشفتات أو الأقسام أو الطلبات.

### طرق الطباعة
1. **خدمة طباعة الجهاز**: تبقى موجودة كخيار عام واحتياطي لأي طابعة لها تعريف/خدمة خاصة.
2. **اتصال حراري مباشر ESC/POS على Android**:
   - Bluetooth Classic للطابعات المقترنة بالجهاز.
   - USB للطابعات المتصلة مباشرة، مع طلب صلاحية USB عند أول استخدام.
   - Wi‑Fi / LAN عن طريق IP وPort، والـPort الافتراضي 9100.

### العربية والكردية
الإيصال يُجهّز أولًا كصفحة PDF ثم يُحوّل إلى صورة Raster قبل إرسالها للطابعة ESC/POS. هذا يتجنب مشاكل ترميز العربية/الكردية الموجودة في كثير من الطابعات الحرارية الرخيصة.

### إعدادات الطابعة
- طريقة الاتصال: خدمة النظام / مباشر ESC/POS.
- Bluetooth / USB / Wi‑Fi-LAN.
- اختيار الطابعة وحفظها على الجهاز.
- فتح إعدادات Bluetooth لإقران طابعة جديدة.
- 58 / 76 / 80 / 112 mm + مخصص.
- اختبار طباعة.
- مطبخ / كاشير.
- عدد النسخ.
- محتوى الورقة.
- طباعة تلقائية بعد قبول الطلب.
- قص وجرس إذا كانت الطابعة تدعم أوامر ESC/POS المقابلة.

### التوافق
الاتصال المباشر يستهدف طابعات ESC/POS القياسية. بعض الموديلات المغلقة ببروتوكول خاص قد لا تقبل ESC/POS، ولهذا لم نحذف خيار خدمة طباعة النظام.

### ملاحظات مهمة
- لا يوجد SQL جديد لهذه المرحلة.
- لا توجد تغييرات على جداول Supabase.
- لم يتم تغيير منطق الشفتات أو ترتيب الأقسام أو المنتجات.
- الاتصال المباشر العام مفعّل على Android. على iOS/المنصات الأخرى يبقى خيار خدمة طباعة النظام هو المسار المتوافق.
- ملف `key.properties` بقي كما كان في المصدر الذي وصل إلى هذه المرحلة. إذا كنت صححت كلمة مرور التوقيع محليًا بعد إرسال المصدر، انسخ ملف `key.properties` المصحح عندك قبل بناء Release ولا تنشئ مفتاح توقيع جديد.
