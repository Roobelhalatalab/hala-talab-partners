# Stage 208 Fix 4 — إشعارات المتجر على أكثر من جهاز

هذا الإصلاح مخصص لحالة فتح نفس حساب المتجر على أكثر من موبايل/تابلت/iPad.

## ما تم تغييره
- لكل تثبيت للتطبيق معرف محلي ثابت ومستقل لا يعتمد على رقم الجهاز أو بيانات شخصية.
- تسجيل Push صار صفًا مستقلًا لكل جهاز/تثبيت بدل احتمال استبدال جهاز بآخر.
- تدوير FCM Token يحدّث الجهاز نفسه فقط ولا يحذف توكنات الأجهزة الأخرى لنفس المتجر.
- Edge Function `send-push` يقرأ جميع التوكنات الفعالة للحساب ويرسل الإشعار لكل واحد منها.
- بقيت الجلسات والطلبات والتقارير والطباعة وبقية أجزاء التطبيق بدون تغيير.

## المطلوب في Supabase قبل الاختبار
1. نفّذ مرة واحدة: `supabase/stage_208_fix4_multi_device_push.sql`.
2. انشر النسخة الموجودة من Edge Function: `supabase/functions/send-push/index.ts`.
3. افتح نفس حساب المتجر على جهازين، وافتح التطبيق مرة على كل جهاز بعد تسجيل الدخول حتى يسجل كل جهاز توكنه.
4. أرسل طلبًا جديدًا. المفروض يصل Push للجهازين، وحالة الطلب تتحدث على الجهازين عبر Realtime.

مهم: تثبيت APK وحده لا يغيّر Edge Function الموجودة على Supabase؛ لذلك نشر `send-push` جزء أساسي من هذا الإصلاح إذا كانت النسخة المنشورة قديمة.

## تصحيح SQL مدمج في النسخة الكاملة
تم تصحيح ملف `supabase/stage_208_fix4_multi_device_push.sql` داخل هذه النسخة نفسها بحيث يتم تحويل أسماء أعمدة القيود إلى `text` قبل المقارنة، لتجنب خطأ PostgreSQL: `operator does not exist: name[] = text[]`.
هذه النسخة هي النسخة الكاملة المعتمدة لـ Fix 4، ولا تحتاج إلى ملف تصحيح خارجي منفصل.
