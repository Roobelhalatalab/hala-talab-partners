# Stage 209 — Partner Profile + Delete Safety

التعديلات محدودة بواجهات الملف الشخصي وحماية حذف الحساب فقط:

1. رقم الهاتف في تعديل بيانات السائق والمتجر يُعرض محليًا بصيغة 07XXXXXXXXX بدل +964/964، مع تحقق صحيح من 11 رقمًا يبدأ بـ 07.
2. التخزين الداخلي يبقى بصيغة العراق الدولية المستخدمة سابقًا، لذلك لم يتغير تسجيل الدخول أو قاعدة البيانات.
3. ملف السائق يعرض الاسم الحقيقي من البيانات الشخصية أو ملف الشريك أو Auth metadata، ويخفي البريد الداخلي @phone.halatalab.invalid.
4. حذف حساب السائق والمتجر أصبح بثلاث مراحل: تحذير واضح، تحقق فعلي من PIN عبر phone-pin-auth، ثم تأكيد نهائي قبل استدعاء delete-partner-account.
5. لم يتم تعديل الطلبات أو الطباعة أو الإشعارات أو الخرائط أو تسلسل الطلبات أو عزل المتاجر.

مهم: شغّل flutter analyze ثم ابنِ APK واختبر بحسابات مؤقتة قبل AAB.
