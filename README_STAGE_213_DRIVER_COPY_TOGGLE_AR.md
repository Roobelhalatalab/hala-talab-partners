Stage 213 - تشغيل/إيقاف نسخة السائق

- إضافة خيار "نسخة السائق" داخل إعدادات الطباعة في قسم نسخ المطبخ والكاشير.
- الخيار محفوظ لكل حساب متجر ضمن نفس إعدادات الطابعة الحالية.
- افتراضيًا مفعّل للحفاظ على سلوك Stage 212.
- عند إيقافه لا تطبع ورقة السائق ولا QR، وتبقى نسخ المطبخ/الكاشير كما هي.
- طباعة الاختبار لا تولد نسخة السائق.
- لم يتم تغيير الإشعارات أو Firebase أو منطق الطلبات.
