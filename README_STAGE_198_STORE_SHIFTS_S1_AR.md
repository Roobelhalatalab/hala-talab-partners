# هلا طلب – Stage 198 / Shift S1

هذه المرحلة تضيف **أساس نظام شفت واحد / شفتين** في Supabase فقط، بدون تغيير واجهات تطبيق المتجر وبدون تغيير تدفق الطلبات الحالي.

## ما تم إضافته
- `stores.shift_mode` وقيمته الافتراضية `1`، لذلك كل المتاجر الحالية تبقى على نظامها السابق بدون أي تغيير.
- `stores.store_timezone` افتراضيًا `Asia/Baghdad`.
- جدول `store_shifts` للشفت الصباحي والمسائي.
- ربط اختياري للأقسام بالشفتات عبر `store_category_shifts`.
- ربط اختياري للمنتجات بالشفتات عبر `store_product_shifts`.
- حماية تمنع ربط قسم/منتج بشفت تابع لمتجر مختلف.
- دالة `hala_shift_is_open` لمعرفة هل الشفت مفتوح الآن، وتدعم الشفت الذي يعبر منتصف الليل.
- RLS في هذه المرحلة يسمح لصاحب المتجر بإدارة شفتاته فقط. قراءة العميل والمنيو العام تؤجل لمرحلتي العميل والمنيو حتى لا نوسع الصلاحيات قبل الحاجة.

## مهم
قاعدة البيانات تحفظ الوقت بصيغة `time` القياسية داخليًا. في Stage S2 ستعرض واجهة المتجر الوقت للمستخدم بصيغة 12 ساعة: **صباحًا / مساءً**، ولن نعرض له نظام 24 ساعة.

## التشغيل
شغّل مرة واحدة في Supabase SQL Editor:
`supabase/stage_198_store_shifts_foundation.sql`

بعد نجاحه، لا تغيّر `shift_mode` يدويًا. Stage S2 سيضيف واجهة المتجر لاختيار شفت واحد أو شفتين وإدخال الأوقات بأمان.
