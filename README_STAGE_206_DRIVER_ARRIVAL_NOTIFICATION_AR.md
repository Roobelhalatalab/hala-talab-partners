# Stage 206 — إشعار «وصلت إلى الزبون»

- مبني على Stage 205.
- يظهر زر **وصلت إلى الزبون** فقط عندما تكون حالة الطلب `picked_up` (قيد التوصيل).
- الزر يرسل إشعارًا واحدًا فقط للزبون عبر `customer_notifications`، وهي نفس قناة إشعارات العميل الحالية.
- يسجل وقت الإشعار في `orders.driver_arrived_at`.
- بعد الإرسال يتحول الزر إلى **تم إشعار الزبون** ويبقى كذلك بعد التحديث وإعادة فتح الطلب.
- يبقى زر الاتصال بالزبون كما هو.
- لا تعديل على الشفتات أو الخرائط أو Waze أو إنهاء الطلب.

## Supabase
شغّل مرة واحدة:

`supabase/stage_206_driver_customer_arrival_notification.sql`

الـRPC عام لكل المتاجر والسائقين والطلبات، ويتأكد أمنيًا أن الطلب مملوك للسائق الحالي وأن حالته قيد التوصيل قبل إرسال الإشعار.
