# Stage 208 Fix 1 — الطلبات الطويلة والطباعة على الورق الثابت

تم تعديل Stage 208 بحيث لا يتم تصغير طلب طويل إلى خط صغير جدًا عند الطباعة عبر خدمة الطباعة العامة في Android.

## السلوك الجديد
- الطابعة الحرارية المباشرة (ESC/POS عبر USB / Bluetooth / LAN): يبقى الخط بالمقاس المختار، ويطول الإيصال مع عدد الأصناف.
- خدمة الطباعة العامة في الجهاز (طابعات مثل Canon / Epson المكتبية): يستخدم الإيصال صفحات ثابتة قصيرة وقابلة للقراءة، وإذا كثرت الأصناف ينتقل تلقائيًا إلى صفحة ثانية وثالثة بدل تصغير الخط.
- أسماء الأصناف الطويلة يمكنها الالتفاف إلى أكثر من سطر بدل تصغير الخط.
- لا تغيير على قبول الطلب أو منطق الطلبات أو الشفتات أو بقية أجزاء التطبيق.

## ملاحظة
الطابعات العامة التي تعتمد Android Print Service قد تظل تعرض نافذة معاينة/اختيار الطابعة حسب تعريف الشركة ونظام Android. هذا التعديل يعالج مشكلة تصغير محتوى الطلب الطويل داخل الورقة الثابتة.
