# Stage 208 Fix 5 — Bluetooth Classic + BLE

هذه المرحلة مبنية على Stage 208 Fix 4 FULL CORRECTED، وتم حصر التعديل في مسار الطباعة عبر Bluetooth فقط.

## ما تم إضافته
- الإبقاء على Bluetooth Classic للطابعات الحرارية ESC/POS عبر SPP/RFCOMM مع طرق الاتصال الاحتياطية الحالية.
- إضافة خيار مستقل Bluetooth Low Energy (BLE) داخل إعدادات الطابعة.
- البحث عن أجهزة BLE القريبة واختيار جهاز وحفظه كطابعة مباشرة.
- الاتصال عبر GATT واكتشاف خدمات الجهاز تلقائيًا.
- البحث أولًا عن أشهر خصائص الكتابة المستخدمة في طابعات BLE الحرارية، ثم أي خاصية Write/Write Without Response متاحة كخيار توافق عام.
- محاولة رفع MTU وتقسيم بيانات ESC/POS إلى دفعات مناسبة للـ BLE.
- دعم خصائص Write و Write Without Response.
- دعم صلاحيات Android 12+ للـ Bluetooth وصلاحية الموقع اللازمة للبحث في إصدارات Android الأقدم.
- اختبار اتصال مستقل لـ BLE قبل الطباعة.

## ما لم يتم تغييره
لم يتم تعديل الطلبات، التسلسل، التقارير، الشفتات، المنتجات، Supabase، send-push، Wi-Fi/LAN، USB، خدمة طباعة النظام، أو منطق قبول الطلب.

## ملاحظة توافق
هذا التوسيع يغطي Bluetooth Classic القياسي ومعظم طابعات BLE التي تقبل ESC/POS عبر خاصية كتابة GATT. بعض الشركات تستخدم SDK أو بروتوكولًا خاصًا وغير قياسي؛ هذه الأجهزة لا يمكن ضمانها بدون تعريف الشركة أو موديل فعلي للاختبار.
